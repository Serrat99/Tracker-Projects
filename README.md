# Lean Project & Activity Tracker

Sistema integral para el seguimiento de proyectos de Mejora Continua (Kaizen, Six Sigma, SGA, Poka Yoke) y **Bitácora de Actividades Diarias**.

## Módulos Integrados:
- **Executive Dashboard**: Tablero de control de proyectos con semáforos de aging, widgets inteligentes y exportación a PDF.
- **Proyectos Lean**: Control detallado, segmentadores, filtros avanzados, importación/exportación a Excel.
- **📖 Bitácora de Actividades**:
  - Feed timeline tipo Teams/Facebook con badges de estatus (Completado, En proceso, Bloqueado) y evidencia adjunta.
  - Indicadores clave y 5 gráficas interactivas en Chart.js.
  - Visión Gerencial del equipo (estatus actual, bloqueos y apoyo requerido por usuario).
  - Alerta de inactividad (+3 días sin registro).
  - Filtros por usuario, fecha, categoría, estatus y búsqueda libre.
  - Exportación a Excel.
